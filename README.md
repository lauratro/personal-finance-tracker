# Personal Finance Tracker

A full-stack personal finance application built to practice modern software engineering and full-stack development.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Mantine UI
- Styled Components
- React Router
- Recharts

### Backend

- NestJS
- Prisma ORM
- PostgreSQL
- JWT Authentication

### Testing

- Jest (Backend)
- Vitest + React Testing Library (Frontend)

### DevOps

- Docker
- GitHub Actions (CI)

---

## Features

- User authentication
- Investment portfolio management
- Dashboard with financial widgets
- Net worth tracking
- Investment history
- Responsive UI

## Running locally

### Backend

```bash
cd apps/backend
npm install
npm run start:dev
```

### Frontend

```bash
cd apps/frontend
npm install
npm run dev
```
